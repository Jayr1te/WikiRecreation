Wiki Recreation for HIC
Made by Neil Bourdius, Jaylin Cooper, and Addison Snider
Made with Unity 6000.5.9f1

How to run the standalone build:
1. Extract the .7z file
2. Run the .exe inside on a Windows Computer

How to run from the source code:
1. Download the Source Code from the Github provided in the PDF
2. Download and Install Unity Hub from the official Unity Website - https://unity.com/
3. Open Unity Hub and use it to install Unity 6000.5.9f1 (Should be in the archived versions, though the newest version of Unity might still work.)
4. Once Unity is installed, in the Projects tab in Unity Hub, click on the Add dropdown and select "Add project from disk"
5. Find the folder which contains everything from the Github, and choose that folder
6. Double-click on the project in Unity Hub after it is finished adding it
